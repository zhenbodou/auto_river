Rust 智能驾驶开发：从小白到工程师

10.4 逐章能力验收与作品集证据

读完不等于会做。本章把每节内容变成“能提交、能复现、能评审”的证据。建议每章按三级自评：

  • L1 解释：不看书讲清概念、假设和失效方式。
  • L2 实现：独立实现并通过测试、基准或数据评测。
  • L3 工程负责：定义接口和预算，处理异常，做 trade-off 并留下评审证据。

目标是主攻方向达到 L3、相邻方向达到 L2、其余方向至少 L1。不存在“所有方向都中高级”的合理短期路线。

第一部分：系统认知

章节最小验收证据
1.1 分级与 ODD为一个 L2+/L4 功能写 ODD、动态驾驶任务分工和退出策略，解释 L2/L3 责任边界。
1.2 软件全景画部署图与数据流，标出进程/ECU、频率、坐标系、deadline 和故障边界。
1.3 五模块流水线用一个行人横穿场景追踪输入输出、时间戳、不确定性与降级传播。
1.4 为什么 Rust写一页 Rust/C++ 选型 ADR，包含生态、认证、FFI、人才和迁移成本。
1.5 行业与岗位选主攻岗位，将 3 个招聘描述拆成能力缺口和 12 周计划。

第二部分：Rust 工程能力

章节最小验收证据
2.1 环境建 workspace CI：fmt、clippy、test、doc、deny/audit，并交叉编译 ARM64。
2.2 所有权处理百万点帧而无整帧 clone；用 benchmark 证明复制和峰值内存。
2.3 trait为传感器驱动设计静态/动态分发接口，解释对象安全、单态化和可测试性。
2.4 错误定义可恢复/不可恢复错误、状态转换和故障注入；关键循环无 unwrap。
2.5 并发构建三节点有界管线，测过载时队列、丢帧、p99 和关闭行为。
2.6 crate 生态为线代、序列化和运行时各写选型表，检查维护、许可证、unsafe 与平台。
2.7 性能/FFI提交 profile 前后证据；封装一个 C API 并审计所有权、panic 和线程契约。

第三部分：传感器与几何

章节最小验收证据
3.1 传感器为雨夜高速 ODD 做传感器覆盖/失效矩阵和冗余方案。
3.2 坐标系实现 SE(3) 复合/逆的属性测试，覆盖单位、左右手系和四元数归一化。
3.3 时间同步对 20 ms 偏移做运动误差实验，实现插值、过期和乱序处理。
3.4 数据模型设计版本化消息；比较 AoS/SoA、复制/共享和序列化成本。
3.5 标定合成外参/时间偏移估计，报告退化、独立验证与在线漂移检测。

第四部分：感知

章节最小验收证据
4.1 总览为一个 ODD 定义检测/跟踪指标、距离分桶、工作点和下游契约。
4.2 图像实现 letterbox/反映射，使用 golden image 与边界尺寸测试。
4.3 推理导出并运行 ONNX；校验 Python/Rust 数值、NMS、p99、峰值内存和冷启动。
4.4 点云在固定数据集运行下采样—地面—聚类，报告精度、复杂度和百万点基准。
4.5 跟踪融合制造遮挡/漏检/异步观测，报告 IDSW、协方差一致性和门控效果。
4.6 数据闭环建数据 manifest、分桶评测、置信区间和模型发布/拒绝报告。

第五至七部分：定位、规划与控制

章节最小验收证据
5.1 卡尔曼用 NEES/NIS 或残差检查一致性，测试奇异矩阵、野值和 Q/R 敏感度。
5.2 定位回放 GNSS 中断/跳变/IMU bias，量化漂移并验证 Degraded 状态机。
5.3 SLAM/地图解释前后端与 gauge freedom；实现小型位姿图或地图拓扑查询测试。
6.1 预测比较 CV、车道跟随和多模态基线，报告 ADE/FDE、miss rate 与概率校准。
6.2 规划实现至少一种搜索和一种轨迹生成；验证碰撞、动力学、连续性和 deadline。
6.3 决策用 FSM/行为树覆盖路口场景，测试优先级、迟滞、不可达状态和保守降级。
7.1 车辆模型对不同积分步长做收敛测试，用参数误差展示模型失配。
7.2 控制同场景比较 PID/Pure Pursuit/Stanley 或 MPC，报告横向误差、超调、jerk、延迟鲁棒性。

第八、九部分：系统、测试与安全

章节最小验收证据
8.1 中间件对每条边选通信模式/QoS/容量，解释丢包、重启和网络分区语义。
8.2 ROS 2两节点发布订阅 + launch/参数/QoS 测试，证明不兼容 QoS 可被诊断。
8.3 Zenoh/DDS在同机/跨机测吞吐、p99 和丢包；解释 discovery 与安全配置。
8.4 消息做 schema 演进兼容测试；录制、索引并回放含大消息的数据。
8.5 运行时过载/崩溃/时钟异常下证明内存有界、数据新鲜且 trace 可定位根因。
9.1 仿真定义确定性场景、种子和真值接口，说明 SIL/HIL 各自能发现什么。
9.2 测试单元/属性/回放/闭环各一组；生成场景覆盖和失败最小复现。
9.3 安全实时部署建 deadline/WCET 证据，定义 watchdog、panic 和部署回滚策略。
9.4 网络安全完成威胁模型、SBOM、签名 A/B OTA 与失败回滚测试。
9.5 安全论证ODD—危害—需求—设计—测试可追踪，并完成故障注入/MRM 证据。

评分规则

每项 0—3 分：0 无证据；1 能解释；2 可复现实验；3 有需求、异常/性能测试、权衡和评审记录。主攻方向对应章节平均不得低于 2.5，任何安全/系统硬门禁不得为 0。

小结

中高级不是阅读进度，而是能否在约束下负责结果。把本章表格放进仓库，每一格只接受可复现证据，不接受“我懂了”。
