Rust 智能驾驶开发：从小白到工程师

后记与延伸资源

走到这里

如果你是一页一页读到这里的——而不是直接翻到最后想看看结局——那么先停下来，认认真真给自己一个肯定。

翻开这本书的第一页时，"自动驾驶"对你可能还是路上那辆顶着激光雷达、有点科幻的测试车。现在，你能画出它体内那条感知→定位→预测→规划→控制的数据流，能说清每个模块吃什么、吐什么；你手写过卡尔曼滤波，调过 PID 的积分饱和，让一辆仿真的车平滑地停在了横穿的行人前；你知道了 Rust 的所有权不是来折磨你的，而是在编译期替你挡住那些会在车上变成事故的 bug。

这中间隔着的，是几个月的编译错误、调不通的坐标系、发散的数值和"这地方为什么又不对"的深夜。那些卡住你的时刻，才是你真正长本事的时刻。 顺畅读完的章节你很快会忘，被你死磕过的那几个坑会跟你一辈子。

再说一遍那句最重要的话

前言里我给过你一颗定心丸，这里我把它换个说法再给你一次，因为它是这整本书的骨头：

中高级工程师，是"读懂原理 + 亲手实现 + 踩过坑"三者叠加出来的。

这本书拼了命想把前两样给足——每个算法都给你数学、给你能跑的 Rust、还唠叨它什么时候会失效。但第三样，"踩过坑"，我给不了你，只有你自己能给自己。它不在书里，在你把第 10.1 节那个最小栈真的跑起来、故意改坏、然后一点点修好的过程里；在你把它接上真实模型、真实中间件、真实数据之后那些"啊，原来现实是这样"的瞬间里。

所以这本书真正的结尾，不是这一页。是你合上它之后，打开终端敲下 cargo run 的那一刻。别让这本书停在"读完"。

一份带走的延伸资源清单

第 10.2 节按方向给过详细的进阶资源。这里是一份更短、更"闭着眼睛也不会错"的精选——每一类挑一两个真正值得你花时间的，带走。

书

  • 《Probabilistic Robotics》(Thrun 等) —— 状态估计与定位的根，一辈子受用。
  • 《视觉 SLAM 十四讲》(高翔) —— 中文最友好、代码最全的机器人几何入门。
  • 《Planning Algorithms》(LaValle，免费在线) —— 规划领域的百科。
  • 《Rust for Rustaceans》(Jon Gjengset) —— 把你的 Rust 从"能写"推到"写得地道"。

课

  • Cyrill Stachniss 的机器人/SLAM 系列（YouTube）—— 讲状态估计讲得最清楚的人之一。
  • 多伦多大学 Self-Driving Cars 专项（Coursera）—— 覆盖全栈、动手强。
  • MIT 6.832 Underactuated Robotics —— 想深入控制/MPC 看它。

开源项目（读源码 + 参与）

  • Autoware（基于 ROS 2 的开源全栈）—— 读它的节点图，就是读一套真系统怎么组织。
  • Apollo（百度全栈）—— 规划/控制模块的工业级参考。
  • CARLA —— 你的免费试验场，把书里的算法放进去跑。

Rust 机器人 / 智驾生态

  • ros2-rust（rclrs） —— 用 Rust 写 ROS 2 节点，最直接的落地。
  • Zenoh —— Rust 写的下一代机器人通信中间件，本身就是极好的 Rust 大型项目范本。
  • tokio / nalgebra / candle / tract —— 异步、线性代数、深度学习推理，你搭项目的四块基石。

社区

  • ROS Discourse、ros2-rust 和 Zenoh 的社区频道 —— 提问、潜水、跟进。
  • arXiv 上的 survey（综述）—— 想快速摸清某个方向的地图，先读一篇综述，别一头扎进单篇论文。

一个提醒：给某个开源项目提一个哪怕只是修文档的 PR，看着它被 merge——那种"我的代码进了真项目"的感觉，比再读十篇教程都更能推着你往前走。而且它会长在你的简历里。

关于 Rust 这一注

我们从头到尾赌了一件事：在智能驾驶里学 Rust，方向是对的。 我依然不骗你——今天车上跑的绝大多数代码还是 C++，Python 依然统治着算法研究。但迁移正在发生：中间件在换、工具链在换、安全攸关的嵌入式在换。你现在会 Rust 又懂智驾，这个组合的人很少。稀缺，就是机会。 你不是在追一个风口，你是在提前占一个位。

守住前言那句务实建议：Rust 当主力，但看得懂 C++、写得动 Python。在真实团队里，能跨语言对话的人，走得最远。

最后

写这本书的人，也曾经是那个对着一屏 Rust 编译错误、对着一个转不对的坐标系发懵的新人。所以我知道你会遇到什么，也知道你能过去。

这个行业缺的从来不是聪明人，是愿意把一件难事做到底、还能对它保持好奇的人。你读到了这最后一页，说明你大概就是这样的人。

书到这里就交给你了。前面九个部分是地图，第十部分是你的第一个脚印。剩下的路，代码替我陪你走。
