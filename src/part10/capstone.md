# 10.5 中高级毕业项目：从最小栈到可评审系统

第 10.1 节证明你能把算法串起来；本章要求证明它在延迟、过载、传感器故障和版本变更下仍然可解释、可测试、可降级。建议 6—10 周完成，并选择感知、定位、规划控制或系统工程之一作为深挖方向。

## 项目场景与 ODD

推荐“结构化道路单车道跟驰 + 静态绕障 + 行人横穿”，仿真速度不超过 15 m/s。先写清：道路/天气/速度、传感器、地图、允许行为、ODD 外条件和 MRM。未声明的能力不算通过。

## 必交架构

```text
scenario/sensors -> perception -> tracking -> prediction -> planning -> safety monitor -> control -> vehicle sim
                         |             |             |               |
                         +------------- trace / metrics / recorder ---+
health + localization ----------------> contracts --------------------+
```

每条边定义 schema、坐标系、采集时间、频率、deadline、freshness、队列容量、溢出策略和失效状态。架构决策用 ADR 记录，至少包含中间件、数据布局、并发模型和模型/算法选型。

## 四个深挖轨道

### A. 感知与融合

接入真实或合成相机/点云，完成推理/聚类与跟踪；建立距离/遮挡/光照分桶、置信度校准和时延 Pareto；实现漏帧、多源分歧和外参漂移处理。

### B. 定位与状态估计

实现含 bias 的 EKF/ESKF，融合 IMU、GNSS 与轮速；用残差门控和状态机处理跳变/中断；报告轨迹误差、NEES/NIS 或等价一致性指标与退化时间。

### C. 规划与控制

实现约束可行的轨迹生成与至少两个控制器；安全监控器独立检查碰撞、曲率/加速度/jerk、数据 freshness；在延迟和模型失配下比较闭环性能。

### D. 系统与平台

把全部节点做成有界、可观测、可回放的运行时；提供 p99 端到端追踪、资源隔离、节点生命周期、schema 演进、签名部署/回滚和故障注入框架。

## 硬门禁

数值按你的硬件和 ODD调整，但必须在实验前冻结，不能跑完再改：

| 门禁 | 示例阈值 |
|---|---|
| 安全 | 必测场景零碰撞；碰撞预测触发后进入定义的 MRM |
| 新鲜度 | 控制使用的轨迹 age p99 < 150 ms，过期输入绝不执行 |
| 实时性 | 关键环节 deadline miss < 0.1%，报告 p50/p95/p99/p99.9 |
| 有界性 | 10 分钟过载下内存无持续增长，所有队列有容量与丢弃策略 |
| 舒适性 | 纵向 jerk/横向加速度不超过预设边界，说明阈值来源 |
| 鲁棒性 | 传感器冻结、20 ms 时间偏移、节点 crash、CPU 压力均有预期状态转换 |
| 可复现 | 固定种子、数据/模型/标定/配置版本；一条命令运行回归 |
| 质量 | fmt/clippy/test/doc/依赖与许可证检查全部通过；关键代码有属性测试 |

## 场景测试集

至少覆盖：正常跟驰、前车急刹、静态障碍、遮挡行人、目标短时漏检、GNSS 跳变/中断、传感器冻结、乱序/过期帧、规划超时、控制延迟、节点重启和 ODD 退出。每个场景有初始条件、随机种子、期望不变量和失败产物。

失败时自动保存最小必要证据：场景配置、版本 manifest、关键 topic、trace、指标和状态机事件。能复现失败，比只展示成功视频更有价值。

## 安全与网络安全交付物

- 一页 ODD 和 MRM；危害清单及 FMEA/FTA 摘要。
- 需求—测试追踪矩阵；至少 5 个故障注入结果。
- 一张威胁模型；SBOM、制品哈希/签名与回滚演示。
- 已知限制和残余风险，明确哪些不能部署到真实道路。

## 性能报告模板

记录硬件、OS/内核、Rust/toolchain、构建 profile、线程/亲和性、输入规模和环境温度。图表至少包含端到端延迟分布、各节点执行/排队时间、队列深度、丢帧、CPU/GPU/内存和一次 profile 火焰图。任何优化同时验证输出等价性。

## 代码评审与答辩

准备 60 分钟答辩：10 分钟 ODD/需求，15 分钟架构与接口，15 分钟主攻算法，10 分钟性能/故障证据，10 分钟权衡和遗留风险。评审者随机选择一个失败场景现场复现，并追问一个替代设计。

不通过的典型原因：只有演示视频；指标只报平均值；队列无界；异常只打印日志；测试数据泄漏；模型/标定版本不明；`unsafe` 无契约；无法从干净环境复现。
