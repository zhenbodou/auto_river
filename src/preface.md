# 前言：这本书能带你到哪里

## 先说句实话

你可能是在某个招聘网站上看到"自动驾驶工程师"的高薪职位，或者在路上看到一辆顶着激光雷达的测试车，然后决定学这门技术。这很好。但请允许我先泼一点点冷水，再给你一颗定心丸。

**冷水**：没有任何一本书能让你"看完就直接上岗"。自动驾驶是横跨*数学、机器人学、机器学习、实时系统、汽车工程*的交叉领域，一线工程师往往在某一个子方向（比如"激光雷达感知"或"轨迹规划"）深耕数年。任何声称"7 天精通自动驾驶"的材料都在骗你。

**定心丸**：这本书可以给你建立中高级岗位所需的知识地图、工程方法和项目验收标准。真正达到职级，还需要在一个主攻方向持续完成可复现项目，并在真实团队中承担交付、评审与故障责任。本书的目标是让你具备进入这段成长的能力和证据，而不是承诺“读完自动升级职级”。

因此本书不满足于"讲清概念"。核心算法给出推导和 Rust 实现或实现骨架，并讨论它在车上会怎么失效。新增的标定、数据闭环、运行时、网络安全和安全论证章节负责把算法放回完整工程系统。第 10.4 节用逐章证据验收理解，第 10.5 节用毕业项目验收系统责任能力。

## 这本书的定位

这是一本**以 Rust 为主语言**的自动驾驶软件开发入门书。它有三条主线交织在一起：

1. **自动驾驶是什么**：一辆车如何"看见"世界、"知道"自己在哪、"预判"别人要干什么、"决定"自己怎么走、最后"操作"方向盘和油门。
2. **Rust 怎么写**：从零讲起，但始终围绕智驾场景选例子——我们不会用"写一个待办事项 App"来教你所有权，而是用"管理一帧点云的内存"。
3. **工程怎么落地**：真实的自动驾驶系统长什么样，用什么中间件、怎么测试、怎么保证安全、怎么部署到车上。

## 关于"Rust 做自动驾驶"这件事，你需要的清醒认知

行业里**目前**的主流仍是 C++（性能 + 历史包袱）和 Python（算法研究、数据处理）。这是事实，我不会隐瞒。

那为什么学 Rust？因为方向对：

- **安全攸关**：一个内存越界在服务器上是崩溃，在车上可能是事故。Rust 在编译期消除了一大类内存和数据竞争问题，这正是汽车安全（ISO 26262）最看重的。
- **正在发生的迁移**：Rust 已被用于中间件、工具链和嵌入式控制器。ROS 2 社区有 `rclrs` Rust 客户端，Zenoh 的参考实现本身就是 Rust 写的。
- **稀缺即机会**：会 Rust *又*懂自动驾驶的人很少。你现在学，是在提前占位。

务实的建议：**把 Rust 当主力，但也要看得懂 C++、写得动 Python**。本书会在关键处对照这三种语言，帮你在真实团队里生存。

## 读完你会获得什么

- 能画出一套自动驾驶系统的完整数据流，并说清每个模块的输入输出。
- 能用 Rust 熟练地处理传感器数据、做坐标变换、跑一个神经网络推理、实现一个卡尔曼滤波器、写一个 PID/纯跟踪控制器。
- 能用 `rclrs` / Zenoh 搭一个多进程的节点通信系统。
- 能在仿真里跑通一个"感知→规划→控制"的最小闭环。
- 懂得实时性、功能安全、测试回放这些工程上真正决定成败的东西。
- 有一份清晰的进阶路线图和面试准备清单。

这些是学习目标，不是只靠阅读就自动获得的结果。只有当你完成逐章验收、毕业项目硬门禁和同伴评审，才应把对应能力写进简历。

## 需要的前置知识

- **数学**：高中数学 + 一点点线性代数（向量、矩阵、坐标变换）和概率。不会没关系，用到时本书会现讲。
- **编程**：任何一门语言的基础经验会让你更快，但**零基础也能读**——第二部分从变量讲起。
- **心态**：这是最重要的。你会遇到编译器报错、数学推导、调不通的坐标系。把它们当成正常的一部分。
