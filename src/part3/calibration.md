# 3.5 传感器标定、运动补偿与在线健康监测

坐标变换矩阵不是配置文件里的常量，而是带估计误差、适用时间和版本的测量结果。中高级工程师要能标定、验证，并在线发现它何时失效。

## 标定问题分四类

- **内参**：相机焦距/主点/畸变，雷达角度偏置等传感器内部参数。
- **外参**：传感器坐标系到车体坐标系的旋转和平移。
- **时间偏移**：两个设备的时钟偏差、传输延迟和触发相位。
- **运动学参数**：轴距、转向传动比、IMU 安装角、轮速比例因子。

不要把时间误差错当外参误差。车辆运动时，固定时间偏移会表现成随速度变化的空间错位。

## 从残差到优化问题

以 LiDAR—相机外参为例，参数为 $T_{CL}$，将激光点投影到图像：

$$
\mathbf{u}=\pi(K,T_{CL}\mathbf{p}_L)
$$

选取边缘、棋盘格角点或自然特征构造残差 $r_i(T_{CL})$，求解：

$$
T^*=\arg\min_T\sum_i \rho(\|r_i(T)\|^2)
$$

$\rho$ 是 Huber/Cauchy 等鲁棒核，用于压低错误匹配。求解器收敛不代表标定正确；退化运动、视野覆盖不足会让某些自由度不可观。

## 可观测性与数据采集

标定数据必须“激励”待估参数：直线匀速很难估计转向比例和横摆相关参数；单一平面难约束某些平移/旋转。采集时覆盖远近、左右、不同深度与转弯工况，并保留独立验证集。

## 点云去畸变（deskew）

旋转 LiDAR 一帧并非同一时刻采完。若车辆在 100 ms 扫描期间运动，直接把整帧当作帧尾姿态会让墙变弯。对点 $p_i$ 使用其采样时刻 $t_i$ 的位姿变换到参考时刻 $t_r$：

$$
p_i^{(r)}=T(t_r)^{-1}T(t_i)p_i
$$

$T(t)$ 可由 IMU/轮速积分并插值得到。实现时明确时间基准、插值方法、外推上限；超过上限应丢帧或降级，不能静默使用错误姿态。

## 标定结果不是一个 YAML 文件

量产标定包至少包含：参数与协方差、传感器序列号/车辆 VIN、坐标系约定、算法/数据版本、生成时间、温度和工况、质量指标、有效期与签名。加载时校验 schema、单位、旋转矩阵正交性、时间范围和硬件身份。

## 独立验证与在线监测

训练/求解数据上的残差会乐观，必须在独立数据上做：

- 重投影误差的分位数和空间热力图；
- LiDAR 边缘与图像边缘对齐度；
- 雷达/激光目标位置和速度差；
- 直行/转弯、近处/远处、昼夜温度分桶。

在线不必每帧重做完整标定，但要监测代理残差并用 EWMA/CUSUM 识别持续漂移。报警需有迟滞，避免在阈值附近抖动。

```rust
struct ResidualMonitor { mean: f64, alpha: f64, bad: u32 }

impl ResidualMonitor {
    fn update(&mut self, residual: f64, limit: f64) -> bool {
        self.mean = self.alpha * residual + (1.0 - self.alpha) * self.mean;
        self.bad = if self.mean > limit { self.bad + 1 } else { 0 };
        self.bad >= 10
    }
}
```

触发后按安全设计执行：标记传感器不可信、切换冗余源、收缩 ODD 或进入 MRM；不要仅打日志后继续满能力运行。

## 本章验收

构造一个带已知外参和 20 ms 时间偏移的合成数据集，加入离群点；估计参数并报告误差、协方差/敏感度和退化案例；实现 deskew 前后点到平面残差对比；设计一次“传感器被碰歪 1°”的在线检测与降级测试。

## 小结

- 标定同时包含空间、时间和运动学参数，必须讨论可观测性。
- deskew 是运动平台点云进入融合/定位前的必要步骤。
- 参数需版本化、独立验证并在线监测，失效后要进入明确降级路径。
